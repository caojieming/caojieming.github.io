[The Odin Project](https://www.theodinproject.com/) is an online course I'm taking on web development.

My Senior Project was also focused on web development. However, that was made mostly through a series of scattered online guides and self-learning, along with a generous amount of assistance from someone who had experience with web development.

The Odin Project is a well-organized curriculum with many smaller projects scattered throughout it. It ensures that anyone following its lessons will have a thorough understanding of what each line of HTML, CSS, and JS does.

As I complete projects throughout the curriculum, I will add links to them here.

## NodeJS

Express, Project 1: Mini Message Board<br>
A web server made using Express.JS that allows you to add, view, and remove messages from a message board. All messages are stored in a PostGreSQL database hosted by [Neon](https://neon.com). The web server itself is hosted on [Render](https://render.com).
Note about Render: I'm using a free Render plan, so when you first access the webpage, it may take a minute for the server to boot up (Render free plan puts the server to sleep if it has no activity for 15 minutes and wakes it up when needed).<br>
[Web Link](https://odin-mini-message-board-36li.onrender.com)<br>
[Github Repo](https://github.com/caojieming/odin-mini-message-board)<br>

Express, Project 2: Inventory Application<br>
An inventory management app for an imaginary store, made using Express.JS. You can add/edit/delete categories and items to the store, and freely add relationships between categories and items (many to many relationship).<br>
(Similar to the previous project, the web server is hosted on Render, and its database is hosted on Neon.)<br>
[Web Link](https://odin-inventory-app-yjj3.onrender.com)<br>
[Github Repo](https://github.com/caojieming/odin-inventory-app)<br>

Authentication, Project 1: Members Only<br>
An exclusive clubhouse app where members can write anonymous posts. You can view all posts and their contents (excluding author and date posted), but in order to add a post, you need to create an account and log in. Account info is stored in an external database, and passwords are encrypted. Accounts have 3 levels of membership (basic, member, and admin) that can be accessed by inputing a specific membership code. Each level hase certain privilages: basic users can add posts but not see authors or dates posted, members can see authors and dates posted, and admins can delete posts.<br>
(Similar to the previous project, the web server is hosted on Render, and its database is hosted on Neon.)<br>
[Web Link](https://odin-members-only-egra.onrender.com/)<br>
[Github Repo](https://github.com/caojieming/odin-members-only)<br>
